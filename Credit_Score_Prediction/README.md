# Credit Score Prediction Project


## Overview

This project uses Machine Learning to predict whether a customer is likely to default on a loan based on financial information such as income, loan amount, loan term, and credit history.

## Objectives

* Analyze customer financial data.
* Handle missing values through data preprocessing.
* Train a Logistic Regression model for prediction.
* Evaluate model performance using accuracy metrics.
* Predict loan default risk for new customers.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Logistic Regression
* Jupyter Notebook

## Dataset Features

* Income
* Loan Amount
* Term
* Credit History
* Defaulted (Target Variable)

## Project Workflow

1. Data Collection
2. Data Preprocessing
3. Missing Value Handling
4. Train-Test Split
5. Model Training
6. Model Evaluation
7. Prediction System

## Model Used

Logistic Regression

## Evaluation Metrics

* Accuracy Score
* Training Accuracy
* Testing Accuracy
